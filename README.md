# kronoscan
![Kronoscan](https://github.com/tailsmonster/kronoscan/blob/main/documentation/logo.png?raw=true)

**kronoscan is a local-first desktop application for tracking time, tasks, and notes.**
**It is designed to work offline, start instantly, and keep data owned by the user.**


## 🎶
  Listen to the Weatherscan's soundtrack while contributing to / using this. Track 27 is incredible.

## Dependancies
- Pocketbase v0.36.0 (./backend/pocketbase)

## What it is
- A desktop-first productivity tool
- Local storage by default
- Focused on logs, tasks, and calendar context
- Optional AI features (bring your own provider)

## Status
  Early development. PC-focused. Architecture and features are evolving.
